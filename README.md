# 社福連ネット（仮称）— 試作デモ

福智町社会福祉法人連携協議会（社福連）の介護BtoB協定事業をデジタル化するWebサービスの**試作（デモ）**です。

## ⚠️ これは試作です

- 画面の見た目と操作感を確かめるための試作であり、実際に稼働しているサービスではありません。
- **掲載している法人名・施設名・空き状況・電話番号・企業名は、すべて架空のものです。** 実在の法人・施設の情報は一切含まれていません。
- 本番では、登録いただいた企業・法人のみがログインして利用する想定です（認証機能は未実装）。
- 「相談フォームへ」「見学・問い合わせ」などのボタンは、リンク先が未実装のため動作しません。

## 画面の構成

| 画面 | 内容 |
|---|---|
| [kigyo.html](kigyo.html) | 企業向けページ。案A（道案内）と案B（会員施設の空き状況一覧） |
| [houjin.html](houjin.html) | 法人向けページ。空き状況の更新 |
| [kakunin.html](kakunin.html) | 法人向けページ。AIが公開情報から下書きした掲載内容の確認・確定 |

- 企業向け・法人向けの各ページ上部にある黒い帯のボタンで、3画面を行き来できます。
- 確認画面は `kakunin.html?houjin=<法人ID>` で法人を切り替えられます（省略時はサンプル会）。収録している法人はいずれも架空です。

## 技術構成

データ層（JSON）とUI層（HTML/CSS/JS）を分離した静的サイトです。フレームワーク不使用・ビルド工程なし・外部CDN不使用。

```
kigyo.html / houjin.html / kakunin.html … 各画面
css/                                     … スタイル
js/                                      … 画面ごとのスクリプト
data/                                    … サービス辞典・分野定義・施設データ（すべて架空）
```
